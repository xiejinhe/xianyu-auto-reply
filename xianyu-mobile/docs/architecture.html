启动 → 配置 → 鉴权 → 进入主界面

app/_layout.tsx · stores/config.ts · stores/auth.ts
启动 初始化 配置 / 校验 登录 主界面
要点：verifyToken() 只在有 token 时才调；服务器不可达时不清 token（只告警），避免离线状态被踢出登录。 切换服务器 profile 会重新走一遍初始化，token 与 profile 是分开存的。
连接粒度 每账号一条
心跳 20s
重连 3s→30s 退避
最多重试 10 次

消息实时链路（WebSocket）

lib/ws.ts · app/(tabs)/messages/index.tsx
和 Web 端的差别：Web 一个页面开一条连接、切账号重连；移动端是每个已连接账号各开一条， 切 Tab 不断连，只在 App 退到后台/回前台时按 AppState 做重连判定。发消息不走 WS，走普通 REST。
