================================================================
              闲鱼自动回复系统  ——  使用说明
================================================================

请从上往下看，按顺序做。
整个过程大约 30 分钟，其中大部分时间是电脑自己在忙，你不用管。


================================================================
第 0 步：先确认你的电脑够不够格
================================================================

必须全部满足，缺一个都跑不起来：

  1. Windows 10 或 Windows 11（64 位）
  2. 内存 8 GB 以上（16 GB 会更流畅）
  3. 硬盘至少还有 20 GB 空闲
  4. 电脑的 CPU 虚拟化功能是开启状态

第 4 条看不懂没关系 —— 双击「1-环境检测」会自动帮你查，
如果没开，它会直接告诉你怎么开。


================================================================
第 1 步：安装 Docker Desktop（只需要装这一次）
================================================================

它是干什么的？
  简单说，它像一个"虚拟电脑"。我们这套系统跑在它里面，
  这样你电脑上就不用再装 MySQL、Redis 这些很麻烦的东西了。

  1. 打开浏览器，访问：
     https://www.docker.com/products/docker-desktop/

  2. 点页面上的 "Download for Windows" 下载安装包。
     文件大约 600 MB，需要等几分钟。

  3. 双击下载好的安装包，开始安装：
     · 安装界面里保持 "Use WSL 2 instead of Hyper-V" 是勾选状态
     · 其它选项一路点 OK / Next / Install 就行

  4. 安装完成后它会提示重启电脑，点重启。

  5. 重启后，桌面上会出现一个鲸鱼图标的 "Docker Desktop"。
     双击打开它。

  6. 第一次打开会弹一堆英文窗口，一律点 Accept / OK / Skip 跳过。
     然后等左下角的小圆圈从黄色变成绿色，显示 "Engine running"。

  7. 到这一步就装好了。

【强烈建议做这一步】设置开机自动启动：

     在 Docker Desktop 窗口右上角点齿轮图标 (Settings)，
     找到这一项并勾上：

        Start Docker Desktop when you sign in to your computer

     勾上之后，以后每次开电脑 Docker 会自己启动，
     我们的系统也会跟着自己跑起来，你什么都不用做。


================================================================
第 2 步：把文件解压到电脑上
================================================================

  1. 把收到的压缩包解压出来。

  2. 建议解压到 D:\xianyu 这样的位置：
     · 路径尽量纯英文，不要带中文
     · 不要放在"下载"文件夹或者桌面角落里

  3. 解压后会得到一个叫 xianyu-auto-reply 的文件夹。
     点进去，里面应该有这些内容：

       1-环境检测.bat
       2-一键启动.bat
       3-一键停止.bat
       4-查看状态.bat
       5-重启服务.bat
       使用说明.txt          ← 就是本文件

   【重要】不要把这个文件夹改成中文名字，
     否则启动时会报 "project name must not be empty"。
     保持 xianyu-auto-reply 这个名字就行。

   【注意】Windows 可能会把这个压缩包当成压缩文件预览，
     一定要选"全部解压"，不要直接在压缩包里双击运行。


================================================================
第 3 步：双击运行「1-环境检测」
================================================================

双击「1-环境检测.bat」，它会自动检查你的电脑，几秒钟出结果。

  · 如果全部显示 [ OK ]  → 没问题，进入第 4 步
  · 如果有显示 [ X ]     → 那个项目下面直接写了"怎么办"，
                            照着做，做完再双击一次本文件


================================================================
第 4 步：双击运行「2-一键启动」
================================================================

这是最关键的一步。双击「2-一键启动.bat」，然后就可以不管了。

它会自动完成这些事：
  · 检查文件是否完整
  · 自动配置国内下载加速（不用你操心）
  · 自动启动 Docker
  · 下载并编译所有服务
  · 启动 6 个服务
  · 等一切就绪后，自动帮你打开浏览器

【第一次启动会很慢，这是正常的】

  第一次要在你电脑上现场下载和编译，通常需要 10 到 30 分钟，
  取决于网速。屏幕上会刷很多行字，全部都是正常过程。

  这期间：
    · 不要关闭那个黑色窗口
    · 不要关机
    · 可以去干别的事，让它自己跑

【第二次之后就快了】

  以后每次启动，通常 1 分钟内就能用。


================================================================
第 5 步：登录系统
================================================================

浏览器会自动打开 http://localhost:9000

如果没有自动打开，就手动在浏览器地址栏输入：

    http://localhost:9000

    初始账号： admin
    初始密码： admin123

【登录后第一件事】找到修改密码的地方，把初始密码改掉。


================================================================
第 6 步：添加你的闲鱼账号
================================================================

  1. 点左侧菜单「账号管理」
  2. 按页面提示添加你的闲鱼账号（一般是扫码登录）
  3. 添加成功后，系统就会自动帮你盯消息、自动回复

自动回复的内容和规则，在「关键词」等页面里设置，
页面上都有说明，按提示操作即可。


================================================================
日常使用（只需要记住这两条）
================================================================

■ 平时要做什么？
   什么都不用做。
   开机后等 1 分钟，直接打开 http://localhost:9000 就能用。
   （前提是第 1 步里勾选了 Docker 开机自动启动）

■ 想临时关掉它？
   双击「3-一键停止」。

■ 网页打不开了 / 电脑卡了？
   双击「5-重启服务」，等 30 秒再刷新网页。

■ 想看看它是不是正常运行？
   双击「4-查看状态」。


================================================================
常见问题
================================================================

问：双击 bat 文件，窗口一闪就消失了？
答：说明运行中出错了。右键那个 bat 文件 → 以管理员身份运行，
    这样窗口会停下来不消失，把里面的内容截图发我。

问：网页一直转圈打不开？
答：等 2 分钟再刷新。还不行就双击「5-重启服务」。
    再不行就双击「4-查看状态」，把结果截图发我。

问：提示 "project name must not be empty"？
答：说明文件夹被改成了中文名（或者放在了中文路径里）。
    把文件夹名改回 xianyu-auto-reply 这样的英文名，再重新启动一次。

问：提示端口被占用？
答：找到文件夹里的 .env 文件（默认是隐藏的，需要先在
    资源管理器"查看"里勾上"隐藏的项目"才能看到），
    用记事本打开，把 FRONTEND_PORT=9000 改成 FRONTEND_PORT=8088，
    保存后双击「5-重启服务」。

问：启动时下载很慢，好像卡住了？
答：属于网络问题。关掉窗口，重新双击「2-一键启动」，
    它会接着上次的进度继续下载，不会白费。

问：电脑重启后服务是不是就没了？
答：只要第 1 步勾选了 Docker 开机自动启动，就会自动恢复。

问：电脑关机了会怎样？
答：服务只在电脑开机并运行时才工作。
    关机 = 自动回复停止。
    如果想 24 小时挂着不关机，需要用云服务器。

问：开机后一定要手动双击「2-一键启动」吗？
答：不需要。Docker 开机自启之后，服务会自动恢复，
    直接打开 http://localhost:9000 就行。

问：我能删掉 Docker 里的数据吗？
答：千万不要。Docker Desktop 里有 "Clean / Purge data" 之类的
    选项，点了会把你的账号和聊天记录全清空。

问：这个文件夹能删吗？
答：不能删。删了就没了，包括启动程序本身。

问：聊天里的「语音转文字」能用吗？要不要另外配置？
答：能用，而且不用配置任何东西。
    系统里已经自带了本地语音识别模型，在你的电脑上直接算，
    不联网、不花钱、也不用填什么 Key。

    第一次点「转文字」时会自动下载识别模型（约 480 MB），
    会慢一点，等这一次就好，以后都是秒出。
    想提前准备好，可以进「系统设置 → 语音转文字」点「下载模型」。

    默认用的模型已经调过，中文准确率和逗号句号问号都正常。
    如果电脑配置比较老觉得慢，可以在同一个页面把模型改成 base
    （约 145 MB），但那样偶尔会认错字、标点也可能丢。

问：那能不能像微信一样，直接发一段语音给买家？
答：暂时发不了真的语音，这是闲鱼网页端的限制，不是本程序的问题。
    闲鱼网页版聊天用的上传通道只收图片，语音文件传上去会被它的
    图片安全审核拦掉（换各种参数都试过，一样被拦）。手机 App 能发语音，
    是因为走的是另一套接口，网页这边没开放。

    所以录音结束后有两个按钮：
      ·「转文字」（蓝色，推荐）——转成文字，确认后按发送，一定发得出去。
      ·「发送语音」——会先试着真发一次；发不出去时会自动转成文字，
        不会再让你白等，也不会把消息丢掉。
    实际回消息用「转文字」就行，跟微信里长按转文字一个效果，还更快。

    想发真语音也不是完全没戏：闲鱼的聊天协议本身是支持语音的，
    卡点只在「语音文件放哪」。如果你把这套系统部署到有公网 IP 的服务器上，
    进「系统设置 → 语音（转文字/发送）」，把「语音消息公网地址」填成
    服务器的外网地址（比如 http://1.2.3.4:8089），语音就会由服务器自己托管，
    买家那边收到的就是能点的真语音了。留空则一律转文字，不会发坏消息出去。


================================================================
最后三个提醒
================================================================

1. 把电脑的自动睡眠关掉：
   设置 → 系统 → 电源和电池 → 屏幕和睡眠 → 都改成"从不"。
   电脑一睡眠，自动回复就中断了。

2. 把 http://localhost:9000 加到浏览器收藏夹，方便下次打开。

3. 遇到任何问题，把出错的窗口整个截图发我。
   截图比文字描述有用 100 倍。
